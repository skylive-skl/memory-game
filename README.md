# Memory Game

Игра на поиск пар: открывайте карточки, запоминайте их расположение и найдите все 8 пар за наименьшее число ходов.

**Деплой:** _ссылка появится после публикации_

## Возможности

- 16 карточек (8 пар), перемешиваются случайным образом (алгоритм Фишера — Йейтса) при загрузке и каждой новой игре.
- Один ход — открытие двух карточек. Совпавшие пары остаются открытыми, несовпавшие закрываются через 1 секунду; пока пара открыта, другие карточки выбрать нельзя.
- Счётчики ходов и найденных пар.
- Модальное окно победы с итоговым числом ходов и кнопками «Новая игра» и «Закрыть».
- Таблица лидеров: 10 лучших результатов (место, ходы, дата) хранятся в `localStorage` и доступны после перезагрузки страницы.
- Модальные окна закрываются кнопкой, кликом по затемнённому фону или клавишей Escape; прокрутка страницы на это время блокируется.
- Адаптивная вёрстка для экранов от 320 px.

## Технологии

- HTML, CSS, JavaScript (ES-модули) без сторонних библиотек и фреймворков.
- Вся разметка создаётся через `document.createElement` (обёртка `src/utils/create-element.js`), в `<body>` файла `index.html` — только `<script>`.
- [Vite](https://vite.dev/) — сервер разработки и сборка.
- ESLint и Prettier. В ESLint добавлены правила, запрещающие `innerHTML`/`outerHTML`, `insertAdjacentHTML`, `document.write`, `DOMParser` и `alert`/`confirm`/`prompt`.

## Локальный запуск

Нужен [Node.js](https://nodejs.org/) версии 20.19+ или 22.12+ (требование Vite).

```bash
git clone <ссылка-на-репозиторий>
cd memory-game
git checkout memory-game
npm install
npm run dev
```

После запуска откройте адрес из терминала (по умолчанию http://localhost:5173).

### Команды

| Команда           | Описание                            |
| ----------------- | ----------------------------------- |
| `npm run dev`     | сервер разработки                   |
| `npm run build`   | production-сборка в папку `dist`    |
| `npm run preview` | локальный просмотр собранной версии |
| `npm run lint`    | проверка кода ESLint                |
| `npm run format`  | форматирование кода Prettier        |

## Структура проекта

```
src/
├── main.js                  # точка входа
├── app.js                   # сборка интерфейса и связь игры с компонентами
├── game/                    # логика игры (без работы с DOM)
│   ├── game.js
│   └── deck.js
├── components/              # хедер, счётчики, поле, карточка, модальные окна
├── storage/leaderboard.js   # работа с localStorage
├── utils/                   # createElement, перемешивание, форматирование
├── data/cards.js            # набор карточек
├── assets/cards/            # изображения карточек
└── styles/main.css
```
